Section 4 of 4 — Portfolio Analyzer + Project Structure

How your existing holdings get analyzed, and how the whole project is laid out

Portfolio Analyzer

You maintain a single holdings.csv file. Update it when you buy/sell. The system reads it and runs full analysis on demand or as part of the evening digest.

Input: holdings.csv (you maintain)
ticker,shares,avg_cost,account
AMZN,30.37,168.40,Robinhood
GOOG,4.16,155.20,Robinhood
META,1.82,420.10,Robinhood
BTC,0.256,38500,Robinhood
ETH,2.72,2800,Robinhood
BTC,0.3,42000,Ledger
...
FUBO is excluded — the analyzer skips it automatically even if you include it.
Output: On-demand portfolio analysis (Slack)
💼 Portfolio Analysis · May 18
Total value: $82,340 · Day P&L: +$1,240
🏆 Best position: BTC +42.1% total return
⚠️ Concern: MSTR overbought RSI 78 · Consider trimming
📊 RISK METRICS
Portfolio beta: 1.42 (higher than market)
Sharpe ratio: 1.18 · VaR (95%): -$2,840/day
Crypto exposure: 38% (above 30% target)
⚖️ REBALANCING SUGGESTIONS
Trim ETH by 20% → rotate into GOOG
Reduce crypto to 30% to lower portfolio beta

Project File Structure

C:\Claude\Trading Analyst\
├── api/
└── main.py              # FastAPI server — 5 endpoints
├── data/
├── market.py            # Polygon.io + yfinance collector
├── news.py              # NewsAPI fetcher
├── earnings.py          # Calendar, beat/miss history, implied move
└── cache.db             # SQLite cache (avoids redundant API calls)
├── smart_money/
├── sec_13f.py           # SEC EDGAR 13F parser
├── ark_flows.py         # ARK daily CSV downloader
├── whale_tracker.py     # Whale Alert + on-chain data
└── congress.py          # STOCK Act scraper + party filter
├── quant/
├── indicators.py        # RSI, MACD, Bollinger, EMA, ATR, Volume
├── forecast.py          # ARIMA + GARCH models
├── signals.py           # Signal combiner + scorer (weights config)
├── confidence.py        # Monte Carlo simulations
├── news_reaction.py     # Claude-powered news classification + divergence
└── backtest.py          # Historical validation, lookahead/survivorship guards
├── portfolio/
├── analyzer.py          # Sharpe, beta, VaR, rebalancing
└── holdings.csv         # ← YOU UPDATE THIS when you trade
├── narrator/
└── briefing.py          # Claude API — turns signals into Slack messages
├── paper_trading/
├── tracker.py           # Phase 1→2→3 P&L + signal attribution ledger
└── trades_log.csv       # Every signal fired + outcome
├── n8n/
├── morning_brief.json   # n8n workflow — imports to your existing instance
├── evening_digest.json  # n8n workflow
└── signal_alert.json    # n8n workflow — 30-min poll
├── config.py              # API keys, signal weights, phase config
├── requirements.txt
└── .env                   # Polygon, Claude, NewsAPI, Slack keys
